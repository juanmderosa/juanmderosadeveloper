## Tech Stack

- **Frontend:** Astro Js, React Js, TypeScript
- **Styling:** CSS, Tailwind CSS
- **Deployment:** Vercel (SSR)

## Características

- Portfolio single-page con secciones: Hero, Sobre Mí, Stack, Proyectos, Opiniones, Contacto
- 18 proyectos en slider interactivo
- 6 opiniones de clientes
- Formulario de contacto con nodemailer
- Diseño responsive (mobile, tablet, desktop)
- SEO optimizado (sitemap, compress)
- Analytics integrado

## getting started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` - Desarrollo
- `npm run build` - Build para producción
- `npm run preview` - Preview local

## Estructura

```
src/
├── components/   # Componentes principales
├── ui/           # Componentes UI (sliders, botones)
├── layouts/      # Layouts
├── pages/        # Páginas
├── content/      # Contenido (proyectos, opiniones)
├── styles/       # Estilos CSS
├── hooks/        # Custom hooks
├── services/     # Servicios
└── types/        # TypeScript types
```
